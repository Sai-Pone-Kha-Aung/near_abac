# Near ABAC

A streamlined location-based platform built for the Assumption University (ABAC) community to discover apartments, restaurants, and essential services around campus.

## Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: Supabase, PostgreSQL, TanStack Query
- **Authentication**: Clerk
- **Infrastructure**: ImageKit (Media), Google Maps API

## Features

- **Smart Search**: Real-time filtering and category-based discovery.
- **Interactive Maps**: Geographic visualization of all listings.
- **Community**: User reviews, ratings, and favorite management.
- **Listing Portal**: User-submitted content with a robust admin moderation workflow.


## Structure

- `app/` — Application routes and API endpoints.
- `components/` — Modular UI components (Radix UI).
- `lib/` — Configurations and shared utilities.
- `database/` — SQL schemas and migrations.
- `cypress/` — End-to-end testing suite.
