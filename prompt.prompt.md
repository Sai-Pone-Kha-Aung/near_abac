UI Microcopy for Near Abac (Mobile)

Onboarding — short steps (one line each):

1. Welcome to Near Abac — find what's nearby.
2. Allow location while using the app for local results.
3. Browse categories or search instantly.
4. Save favorites and connect with sellers.

Location permission dialog — heading / body / confirm / decline:

- Heading: Enable location
- Body: Let Near Abac show listings near you. We only use location while the app is open.
- Confirm: Allow while using app
- Decline: Enter location manually

Home screen CTAs (primary / secondary):

- Primary: Explore nearby
- Secondary: Show map
- Quick action: Post listing

Search UI — placeholder / empty / hint:

- Placeholder: Search by place, category, or keyword
- Empty results: No results nearby. Try widening your search or adjusting filters.
- Hint: Try "coffee" or "plumber" — or tap a category.

Filter & sort labels (short):

- Distance
- Category
- Price
- Rating
- Newest

Listing card — buttons / labels:

- View details
- Save
- Message seller
- Directions

Listing detail — section titles (short):

- Overview
- Photos
- Location
- Seller
- Reviews

Profile & messaging microcopy:

- Edit profile
- Contact
- Send message
- Verified

Create / Edit listing — field placeholders:

- Title: e.g., Bike for sale
- Price: 0.00
- Location: Select or enter address
- Description: Add details, condition, and contact info
- Photos: Add up to 8 photos

Form validation & errors (short):

- Required: This field is required
- Invalid price: Enter a valid amount
- Upload failed: Couldn't upload image — try again
- Network error: Check your connection and retry

Empty states (friendly):

- No saved items yet — tap "Save" to bookmark favorites.
- No messages — start a conversation about a listing.
- No listings in this category — try another category or add the first listing.

Push / local notification examples (short, <=50 chars):

- New listing near you in {category}
- Price dropped on a saved item
- Someone replied to your message

Short CTA variants (3-word max):

- Explore nearby
- Show map
- Save listing
- Post now

A/B microcopy variants to test (two options each):

- Onboarding step 2a: "Allow location while using the app"
- Onboarding step 2b: "Enable location for local results"

- Empty search A: "No nearby results — try expanding"
- Empty search B: "Nothing here — widen your search"

Accessibility / microcopy notes:

- Use plain language and sentence case for labels.
- Keep CTAs short (1–3 words) for mobile buttons.
- Provide fallback copy for denied permissions (manual location entry).
